# Результаты исследования теплопроводности

## Актуальная серия измерений

Полная серия содержит 6000 измерений: 1200 конфигураций по пять повторений. Для сравнительных графиков используется медиана пяти времен. Варьируются четыре размера сетки, пять профилей компиляции, четыре значения параметра группировки циклов и семь вариантов числа нитей в OpenMP и Pthreads.

В разделе исследования производительности восстановлен **полный набор 11 графиков из первоначального отчёта**; все построены по новым измерениям. Графики сохраняются в [figures/2026/classic/](figures/2026/classic/). Изображения прежней экспериментальной серии, лежащие в старых каталогах, не используются в итоговом отчёте.

Сводка по всем 1200 конфигурациям, используемая генератором: [results/2026/summary_1200.csv](results/2026/summary_1200.csv).

Для повторного построения графиков:

```bash
python3 scripts/generate_report_figures.py
```

## Верификация

Значения погрешности по C- и L₂-норме для десяти устойчивых сочетаний (h, τ) находятся в каталоге [errors/](errors/). Ещё шесть комбинаций нарушают условие устойчивости и отмечены прочерками.

## Сборка отчёта

Титульный лист формируется исходным Lua-фильтром, сохраняются оглавление, оформление A4, нумерация разделов и подразделов, изображения PNG.

```bash
bash scripts/build_pdf.sh
```

## Архив

Ранние сравнительные графики в каталогах `figures/`, `loop/figures/`, `openmp/figures/` и `pthread/figures/` отражают эксперименты до исправлений методики и имеют архивное значение.
